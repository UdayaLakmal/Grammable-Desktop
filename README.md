# Grammable for Windows & Linux

Free, open-source AI writing assistant for Windows and Linux: fix grammar and spelling, change tone,
rewrite and format text in any app, powered by the AI you already have (Claude Code, Codex CLI,
Gemini CLI, Antigravity, Devin, Ollama, LM Studio) or a built-in offline checker.

The Windows and Linux edition of [Grammable for macOS](https://github.com/UdayaLakmal/Grammable).

> **Work in progress.** Nothing is released yet. See [IMPLEMENTATION_NOTES.md](IMPLEMENTATION_NOTES.md).
